# مطالعه تجربی تأثیر نرخ یادگیری و تعداد لایه‌های پنهان بر الگوریتم پس‌انتشار خطا
### Experimental Study on Learning Rate and Hidden Layers in Backpropagation Algorithm

این ریپازیتوری شامل پیاده‌سازی کامل کدهای مربوط به مقاله کنفرانسی با عنوان «مطالعه تجربی تأثیر نرخ یادگیری و تعداد لایه‌های پنهان بر عملکرد الگوریتم پس‌انتشار خطا در شبکه‌های عصبی» است.

## 📋 درباره پروژه
این پروژه یک مطالعه تجربی است که هدف آن بررسی کمی تأثیر دو فوق‌پارامتر کلیدی (نرخ یادگیری و عمق شبکه) بر دینامیک آموزش شبکه‌های عصبی پیش‌خور (MLP) است. تمامی کدها از صفر و تنها با استفاده از کتابخانه NumPy پیاده‌سازی شده‌اند تا جزئیات الگوریتم پس‌انتشار خطا به طور کامل شفاف باشد.

### ویژگی‌های اصلی:
- ✅ پیاده‌سازی دستی شبکه عصبی MLP (بدون استفاده از فریم‌ورک‌هایی مثل TensorFlow یا PyTorch)
- ✅ الگوریتم پس‌انتشار خطا (Backpropagation) با محاسبه دستی گرادیان‌ها
- ✅ تکنیک Early Stopping برای جلوگیری از بیش‌برازش (Overfitting)
- ✅ اجرای خودکار ۱۲ پیکربندی مختلف (Grid Search)
- ✅ مقداردهی اولیه وزن‌ها با روش Xavier/Glorot
- ✅ توابع فعال‌ساز Sigmoid (لایه‌های پنهان) و Softmax (لایه خروجی)
